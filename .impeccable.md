## Design Context

### Users

Etyon is a local desktop agent workbench for developers and technical operators who spend long sessions moving between AI chat, project files, Git changes, terminals, artifacts, and live web pages. The interface should make repeated, parallel work easy to scan and control without interrupting concentration.

### Brand Personality

Quiet, capable, and precise. Etyon should feel like a trustworthy native work surface: technically serious, compact, and responsive, with restrained moments of personality rather than decorative spectacle.

### Aesthetic Direction

Use a dense desktop-tool layout with native-browser familiarity and the existing semantic HeroUI tokens. Preserve Etyon's light and dark themes, liquid-glass compatibility, compact Inter typography, 4 px spacing rhythm, and small-radius controls. Prefer clear hierarchy, stable geometry, subtle state motion, and content-led surfaces. Avoid marketing composition, oversized type, decorative gradients, nested cards, neon-on-dark styling, and animation that competes with work.

### Design Principles

1. Keep the user's work as the visual focus; controls should be compact, predictable, and nearby.
2. Model real workflows directly: tabs are repeatable sessions, not one-off feature slots.
3. Use progressive disclosure for consequential actions while keeping recovery paths visible.
4. Preserve geometry during loading and state transitions, especially around native Electron views.
5. Maintain keyboard access, focus visibility, reduced-motion behavior, and readable contrast in every theme.
